# HCl-GA-Spectroscopy

Simulation Study of the Rovibrational Spectra of the HCl Molecule Using Genetic Algorithms

## Overview

This project investigates the rovibrational spectra of the HCl molecule using Genetic Algorithm optimization of Morse potential parameters.

## Main Results

- Optimization of Morse potential parameters
- Vibrational energy level calculations
- Simulated vs experimental transition energies
- Rovibrational P- and R-branch spectra
- Spectroscopic analysis of the HCl molecule
